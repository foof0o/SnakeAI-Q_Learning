# SnakeAI-Q_Learning

An AI that plays snake with Q-Learning

Please make sure you have installed pygame and matplotlib.

Start the project with:

```
python Snake_Game.py
```

The three gamemodes in the code are:
- 1 snake
- 2 snake fighting for the food
- 1 snake with 15% of the board as an obstacle

The environment size is best kept to small, but it can be changed. The Snake would need to be retrained and the AI is best for the small environment.
